# Assignment9_21
Godot assignment due 9/20. A puzzle game about switching between a Platformer and Top-Down movement by picking up collectibles. The enmeny Only chases you in TopDown. 

The player can Push boxes in TopDown and then jump on them when Platforming. The player must be in platforming mode to pass certain barriers. 

All Assets were made by me, except the image of the mall which is a stock image 

# Controls 
Move - WASD

Jump - SpaceBar

ChangeStates- PickUpCollectible
